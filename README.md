# HR Analytics Dashboard
1.Project Overview

This Power BI dashboard analyzes employee attrition, salary trends, job roles, age groups, and workforce insights to help organizations improve employee retention and decision-making.

2.Tools Used
- Power BI
- Excel
- DAX 

3. Key KPIs
- Total Employees: 1470
- Attrition Count: 237
- Attrition Rate: 16.1%
- Average Salary: 6.5K
- Average Age: 37 Years

4. Dashboard Insights
- Highest attrition observed in Laboratory Technicians
- Most employees leaving belong to the 26–35 age group
- Employees earning up to 5k show the highest attrition
- Life Sciences education field has maximum attrition

5.Features
- Interactive HR Analytics Dashboard
- Attrition Analysis
- Salary Analysis
- Job Role Insights
- Employee Demographics
